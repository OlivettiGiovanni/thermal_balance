# Luke 2015: provenance and digitization

Source: K. Luke et al., *Broadband mid-infrared frequency comb generation in a Si3N4 microresonator*, Optics Letters 40, 4823–4826 (2015), [DOI 10.1364/OL.40.004823](https://doi.org/10.1364/OL.40.004823), Figure 1. The CSV traces the solid green real index and solid red extinction coefficient. The blue and dotted Sellmeier curves are excluded.

The optical test specimen is a 340 nm LPCVD Si3N4 film on 3.1 µm thermal SiO2/silicon, annealed for 3 h at 1200 °C. Its numerical residual stress is not established. The paper describes ellipsometric characterization and Lorentzian/Gaussian fitting; the CSV is digitized from those displayed fitted curves, not raw ellipsometry data. No high-temperature optical constants are supplied.

The original PDF was obtained on 9 October 2026 through the [Lipson group's publications page](https://lipson.ee.columbia.edu/publications): [author-hosted PDF](https://lipson.ee.columbia.edu/sites/lipson.ee.columbia.edu/files/content/Broadband%20mid-infrared%20frequency%20comb%20generation%20in%20a%20Si3N4%20microresonator%20.pdf). Figure 1 is a 1000 × 412 pixel embedded JPEG, not a vector plot.

## Recovery and accuracy

The horizontal calibration uses the six ticks from 5 to 30 µm. The vertical axes use n = 0–4 and k = 0–2.5. Tick positions and calibration coefficients are recorded in `sin_luke_2015.json`. One pixel corresponds approximately to 0.035 µm, 0.0135 in n, and 0.0084 in k.

Color masks isolate the curves. Their median vertical pixel position is extracted in each column; inset and legend regions are excluded. Two short green-curve gaps hidden by the red curve (columns 268–271 and 365–366) are linearly interpolated. `luke_2015_pixels.csv` preserves this numerical trace and flags interpolated columns; it is an audit input to the digitizer, not an optical spectrum for the thermal solver.

The output contains 303 rows at 0.1 µm intervals, spanning **1.4–31.6 µm**. Although the caption specifies 32 µm, the visible curves end near 31.65 µm; the CSV does not extrapolate to 32 µm. Values of n and k are rounded to 0.01. Approximate graphical resolution is **0.03 in n and 0.02 in k** due to line thickness and overlaps; these are not experimental error bars or global error bounds.

Values of k below the graphical threshold 0.02 are stored as zero. These graphical zeros cover 1.4–5.0 µm, 5.5–5.9 µm, 6.5 µm, and 7.0–7.2 µm on the output grid. **They do not establish zero material absorption.** This uncertainty matters when shorter wavelengths contribute significantly to thermal radiation. Neither denser interpolation nor the laser absorption coefficient can recover the missing spectral information.

The digitized curves were visually overlaid on the original figure. Checks include n = 0.65 near 9.0 µm, n = 3.73 near 12.8 µm, k = 2.36 near 11.3–11.4 µm, and the secondary k = 0.85 peak near 20.5–20.6 µm. Replay from the saved numerical trace reproduces the CSV byte for byte. This checks the graphical recovery, not accuracy against an unavailable original numerical dataset.

## Reproduce

From the project root, rebuild the supplied CSV using NumPy and the included numerical trace:

```bash
python data/digitize_luke_2015.py
```

For a fresh extraction and visual overlay, download the linked author PDF yourself and run:

```bash
python data/digitize_luke_2015.py --source /path/to/luke_2015_author.pdf
```

Fresh PDF extraction additionally requires PyMuPDF and Pillow; plotting uses Matplotlib. The script checks the source hash before applying the calibration. It creates `data/luke_2015_overlay_qa.png` for inspection. The copyrighted source PDF and figure are not included in this project. None of these recovery steps is required to run the thermal solver with the included CSV.
